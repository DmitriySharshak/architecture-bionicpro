Контейнер: BFF API 
Единая точка входа для фронтенда. Реализует Server-side OAuth2 flow (PKCE), управляет сессиями через HttpOnly cookies, проксирует запросы к внутренним API.
- Взаимодействует: Приложение (Android/iOS) -> BFF (https)
- Взаимодействует: BFF -> Keycloak (валидация/логин)
- Взаимодействует: BFF -> API (старый запрос данных)

Контейнер: Identity Provider [Keycloak]
Федеративный шлюз для входа через соцсети/Госуслуги. Отвечает за выпуск JWT.
- Взаимодействует: BFF -> Keycloak (OIDC)

Контейнер: Analytics DB [ClickHouse]
Колоночная БД для хранения временных рядов (миосигналы, телеметрия).
- Взаимодействует: ETL (Airflow) -> ClickHouse (запись)
- Взаимодействует: BFF -> ClickHouse (чтение для отчетов)
